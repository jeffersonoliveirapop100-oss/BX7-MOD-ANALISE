# BX7 MOD - Call of Duty: Black Ops II (T6 Zombies) - Source Codes & Scripts

Repositório contendo todos os códigos-fonte, scripts Lua, definições de armas, menus e configurações do **MOD BX7** (Versão 1.9.0) para Plutonium T6 (Black Ops 2 Zombies).

## 📋 Informações do Mod
* **Nome:** BX7_MOD
* **Versão:** 1.9.0
* **Créditos:** Pro7xt, Guilh_INFR, aiuzy, huk776

## 📁 Estrutura dos Códigos
* **`ui_mp/t6/`**: Scripts em Lua da interface do usuário (HUDs, Menus, Wunderfizz, Pack-a-Punch, WorkBench, Competitive Scoreboard).
* **`weapons/zm/`**: Scripts e definições de comportamento das armas Zombies (Freezegun, Tesla Gun, Thundergun, Ray Gun Dual Wield, M79, Minigun, etc.).
* **`configs/`**: Configurações de jogador e DVARs do mod.
* **`mod.json`**: Metadados oficiais do Mod.
